## Capture provenance

All PNGs here were generated by the DEBUG-only `arrange-preview` command from
ArrangeChecks.swift and the production ArrangeHUD/ArrangeOutlineView. The
fixtures use synthetic Terminal/Aside/Zen/Notes window records, generic window
glyphs and authored plain desktop backgrounds. No user window was resized,
captured or activated. Control-only PNGs include transparent margins from native
view capture; they are not cropped user screenshots. Native controlActiveState
is set to key in fixtures to show the active panel treatment without ordering a
window onto the user's desktop.

Full preview logical sizes: portrait 1440×2560, landscape 1920×1080. Control
views are 540×170 or 540×320 logical points; PNG backing resolution follows the
host's capture scale. The four full-screen views and the light/dark control
states were rendered; visual review sampled the full-screen views plus expanded,
empty, permission and result states. Unseen pixels are not physical acceptance.
